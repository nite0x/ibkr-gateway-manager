远程监听的安全要求监听主机不是本机回环地址时，每个实例必须配置代理访问密钥，公开 URL 必须是 HTTPS，并提供 TLS 证书与私钥。

管理 API Token

供外部程序调用管理 API，具有全部实例的管理权限。生成后立即保存并生效，旧 Token 立即失效。完整值仅在生成时显示，请复制保存。

请求头：Authorization: Bearer <token>。访问单个 IBKR 实例请使用该实例的 Proxy Token。
